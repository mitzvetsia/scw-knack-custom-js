How this works / monthly workflow
  • Export 1 — shipped items: the ShipEdge processed-shipments report for the month (the file with Ship#, Qty, Processed_at columns).
  • Export 2 — item data: the ShipEdge products export (the file with Cost, Available, In Warehouse columns). Costs are whatever ShipEdge holds on export day — pull it right after month close so the “latest cost” approximation stays tight.
  • Every shipped line is joined to its item cost: qty × cost. The tiles give the MJ numbers; type the tariff total from the FIFO tracker to get the full journal.
  • Download cost shipped / item CSV (or copy/paste) feeds the herr cheetoh FIFO tracker, same as the old tab. The shipment-detail CSV has per-shipment dates if you ever want FIFO at day grain.
  • Quirks handled automatically (each one shows up under Data quality when it fires): SKUs with stripped leading zeros, shipped rows the ShipEdge writer breaks apart when a description contains inch marks (\") or line breaks, MySQL-style \N nulls and \" escapes in the products export.
  • Everything runs locally in your browser — no data leaves this page.
